## Воспроизведение

На выделенном тестовом Android/AVD из корня проекта:

```sh
flutter test integration_test/table_presets_test.dart -d emulator-5554
```

Для физического устройства заменить ID на фактический. Flutter устанавливает
инструментированную сборку; не использовать телефон участника с нужным прогрессом
без отдельного согласования установки. Эта проверка не измеряет понятность
обучения, реальные split/длинные руки или эффект увеличенного системного текста.
Эти сценарии остаются в `FEEDBACK_RETEST_REPORT.md` для наблюдения.

Эмулятор не закрывает физический smoke, повторное подтверждение автора отзыва
или недельный пользовательский gate Free-beta. Записи участников не созданы.
