# Доступность игровых уроков Learn

Итерация 20, 2026-09-07. Область: три пилотных урока, межблочная практика и
отдельные проверки. Это автоматическая техническая проверка, не замена пилоту
с людьми или ручному тесту TalkBack/VoiceOver на устройстве.

## Реализовано

- При ширине 320px или крупном тексте панели дилера и игрока располагаются
  вертикально. Карты масштабируются вместе с рангом; увеличивается сама карта,
  а не только надпись внутри фиксированного прямоугольника.
- Скринридер получает одно локализованное название карты: ранг и масть.
  Повторяющиеся декоративные символы исключены из semantic tree. Закрытые
  карты и ответы не раскрываются; в самостоятельном счёте теги/итог скрыты.
- Красные и чёрные обозначения карт Learn проверены на контраст не менее
  4,5:1 с фоном. Стандартный вид карт Table не изменён.
- Действия, открытие следующей карты и ввод RC выполняются кнопками. Нет
  обязательного игрового свайпа, перетаскивания или различения только по цвету.
- Исправление ответа, результат checkpoint и ошибки сохранения объявляются
  через live-region. Баннер ошибки ограничен четвертью высоты экрана и
  прокручивается: при тексте 200% он не закрывает область повторного ввода.

## Автоматические проверки

`test/presentation/learn/learn_accessibility_test.dart` проверяет EN/RU,
320×568, текст 100% и 200%, подписи карт без повторов, фактическое увеличение
карт, контраст и Flutter guidelines для размеров/подписей tappable targets.

Полные маршруты уроков, адаптации и checkpoint выполняются при тексте 200%,
включая восстановление после выхода, ошибку записи и повторную попытку.
Тестовый helper перед каждым нажатием проверяет `hitTestable`: наличие виджета
в дереве само по себе не считается доступным управлением.

Перед публичным выпуском остаются ручные проверки на реальных Android/iOS:
порядок фокуса TalkBack/VoiceOver, системные нелинейные масштабы текста,
ориентации и читаемость объяснений целевой группой.
