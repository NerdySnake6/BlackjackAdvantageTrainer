## A — Русский

В бесплатном тренере уже доступны правила, базовая стратегия, текущий счёт
Hi-Lo и совместная практика стратегии со счётом.

Pro планируется как дополнительный учебный курс из 32 уроков:

| Тема | Что предлагается тренировать |
| --- | --- |
| Оценка оставшихся колод | Оценивать количество карт по учебной стопке и разбирать ошибку оценки. |
| True count | Учитывать остаток колод при пересчёте текущего счёта; различать ошибки оценки, деления и округления. |
| Отклонения от базовой стратегии | Разбирать, когда проверенное правило меняет действие, а когда оно остаётся прежним. |
| Ставки и риск | Сравнивать учебные модели дисперсии и риска в условных единицах, понимать их ограничения. |
| Выбор правил игры | Сравнивать только независимо проверенные профили правил. |
| Комплексная практика | Совмещать навыки в учебной раздаче и проверять их на новых задачах. |

Сейчас этих готовых Pro-уроков в приложении нет. Материал и математические
примеры должны пройти независимую проверку до публикации. Срок выпуска
не установлен. Это автономная симуляция: она не считывает реальные карты,
не подключается к казино и не обещает заработка. Учебные результаты не
гарантируют будущего выигрыша.

Какую из этих задач вы уже пытаетесь решить? Что было бы полезно лично вам?
Ответ «никакую» тоже подходит.

## A — English

The free trainer already offers the rules, basic strategy, the Hi-Lo running
count, and combined strategy-and-count practice.

Pro is planned as an additional course with 32 lessons:

| Topic | Planned practice |
| --- | --- |
| Deck estimation | Estimate remaining cards from a simulated stack and review estimation errors. |
| True count | Use the remaining decks to convert running count; separate estimation, division and rounding errors. |
| Playing deviations | Learn when an independently checked rule changes the basic-strategy action and when it does not. |
| Betting and risk | Compare educational models of variance and risk using fictional units, including their limitations. |
| Game rules | Compare only independently validated rule profiles. |
| Combined practice | Combine these skills in simulated hands and check them on new tasks. |

These completed Pro lessons are not currently available in the app. Content and
mathematical examples require independent review before publication. No release
date has been set. This is a standalone simulation: it does not read real cards,
connect to casinos, or promise income. Training results do not guarantee wins.

Which of these tasks are you already trying to solve? What would help you
personally? “None” is a valid answer.
