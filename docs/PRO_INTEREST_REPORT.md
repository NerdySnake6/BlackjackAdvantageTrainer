# Итерация 31 — пустой бланк результатов

Заполненные копии и контакты хранить вне Git. Пустые поля — отсутствие данных,
а не ноль или отказ. Участников и ответы в этом шаблоне нет.

## Состав и гипотеза

- Даты интервью / организатор:
- Версия карточки / цена / валюта / формат оплаты:
- Критерий активности, зафиксированный до набора:
- Приглашены / отказались / завершили интервью:
- Подтверждённо активны / недостаточно сведений / не соответствуют критерию:
- Основание активности и способ получения согласия:
- EN / RU; группы по версии цены анализируются отдельно:

## Один участник — отдельная копия

- Обезличенный код:
- Дата / язык / используемая версия Free и карточки:
- Количество реальных занятий за последние 7 дней; самостоятельные отдельно:
- Источник подтверждения активности / missing:
- Последняя конкретная задача и затруднение:
- Нынешняя альтернатива; время и добровольно сообщённые расходы:
- Понимание Free / планируемого Pro до пояснения организатора:
- Первая полезная тема или «ни одна»; почему:
- Необходимый результат / чего не хватает в описании:
- Реакция после показа цены: рассмотрел бы / не рассматривает / не определился:
- Причина; что нужно проверить перед решением:
- Желаемый пробный фрагмент и признак его пользы:
- Обезличенная цитата с согласия участника:
- Интерпретация организатора (отдельно от цитаты):

## Сводка после интервью

| Наблюдение | Число / знаменатель | Фактическое основание / missing |
| --- | --- | --- |
| Подтверждённо активные участники | | |
| Понимают, что Pro пока планируется | | |
| Называют конкретную отдельную задачу | | |
| Выбор первой темы (по каждой теме отдельно) | | |
| Уже используют альтернативу (по типам отдельно) | | |
| Рассмотрели бы предложение по данной цене | | |
| Не рассматривают / не определились (отдельно) | | |

Реакции на гипотезу не являются покупками или прогнозом выручки.
Не исключать неудобные ответы; не объединять разные ценовые версии.

## Решение владельца

- Дата / рассмотренные данные:
- ≥10 подтверждённо активных участников: да / нет / не проверено:
- Реакция на фиксированную цену собрана: да / нет / не проверено:
- Free-beta: статус и ссылка на отдельный фактический отчёт:
- Решение: небольшой фрагмент / переработать гипотезу / приостановить / данных мало:
- Основание и повторяющиеся возражения:
- Разрешённый следующий объём и оставшиеся зависимости:

Без фактических интервью статус итерации 31 — подготовка, gate открыт.
